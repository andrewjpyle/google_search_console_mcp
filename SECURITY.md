# Security

Please report a vulnerability privately through GitHub's
[security advisories](https://github.com/andrewjpyle/google_search_console_mcp/security/advisories/new)
rather than a public issue.

Things that count: a way for a tool call to act on a property outside
`GOOGLE_SEARCH_CONSOLE_SITE_URLS`, credentials appearing in output or logs, or anything written to
stdout that is not an MCP protocol message.
